#  Code Explanation Tutor

An AI-powered web application that helps beginners understand Python programs through simple, beginner-friendly explanations.

## Problem Statement

Students and beginner programmers often find it difficult to understand existing Python programs, especially functions, execution flow, and data flow.

## Solution

Code Explanation Tutor allows users to upload a Python `.py` file and ask questions about the code. The AI analyzes the uploaded program and provides an easy-to-understand explanation.

## Features

-  Upload Python `.py` files
-  View uploaded source code
-  Display code statistics
-  AI-powered code explanations
-  Quick questions
-  Ask custom questions
-  Explain functions
-  Explain execution flow
-  Explain data flow
-  Basic validation and error handling

##  Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
